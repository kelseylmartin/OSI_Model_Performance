Introduction to the Optics Package

1. Introduction

The Optics package provides a standardized toolkit for evaluating the performance of machine learning models on optical survey data. This vignette demonstrates a complete workflow, from ingesting raw model output to generating final performance metrics and visualizations.

First, let’s load the Optics package and other useful libraries like dplyr.

library(Optics)

3. Summarizing Performance by Threshold

A key task is to evaluate how a model performs at different confidence thresholds. The summarize_performance_by_threshold() function automates this by calculating metrics like precision, recall, and F1-score for each threshold.

We will run this for each model separately and then combine the results.

# Define the thresholds we want to test
thresholds_to_test <- seq(0.5, 1.0, by = 0.1)

# Analyze Model A
perf_model_a <- summarize_performance_by_threshold(
  model_detections = filter(model_detections, model_name == "Model A"),
  truth_detections = truth_detections,
  by = c("video_id", "category_name"),
  thresholds = thresholds_to_test
) %>% mutate(model_name = "Model A")

# Analyze Model B
perf_model_b <- summarize_performance_by_threshold(
  model_detections = filter(model_detections, model_name == "Model B"),
  truth_detections = truth_detections,
  by = c("video_id", "category_name"),
  thresholds = thresholds_to_test
) %>% mutate(model_name = "Model B")

# Combine into a single data frame
performance_summary <- bind_rows(perf_model_a, perf_model_b)

print(performance_summary)

4. Visualizing Performance

With the summary data, we can now create plots to compare the models.

Performance by Threshold Plot

The plot_performance_by_threshold() function is perfect for visualizing the trade-offs between precision, recall, and F1-score. This helps in selecting an optimal confidence threshold for each model.

plot_performance_by_threshold(
  performance_summary,
  model_col = model_name,
  title = "Model Performance Comparison"
)

Count Comparison Scatterplot

To see how well the model counts match the truth counts at a specific threshold (e.g., 0.8), we can generate a scatterplot.

# First, calculate counts at a chosen threshold
model_counts_at_08 <- model_detections %>%
  filter(score >= 0.8) %>%
  calculate_maxn(group_cols = "model_name")

truth_counts <- calculate_maxn(truth_detections)

# Align each model's counts to the truth separately, then combine.
aligned_a <- align_counts(
  model_counts = filter(model_counts_at_08, model_name == "Model A"),
  truth_counts = truth_counts,
  by = c("video_id", "category_name")
) %>% mutate(model_name = "Model A")

aligned_b <- align_counts(
  model_counts = filter(model_counts_at_08, model_name == "Model B"),
  truth_counts = truth_counts,
  by = c("video_id", "category_name")
) %>% mutate(model_name = "Model B")

# Combine the aligned results into a single data frame for plotting
aligned_counts <- bind_rows(aligned_a, aligned_b)

# Generate the plot, faceting by model
plot_counts_scatterplot(
  aligned_counts,
  model_col = model_name,
  title = "MaxN Counts at 0.8 Confidence"
)
Model vs. Truth MaxN counts at a 0.8 confidence threshold.

This vignette provides a basic overview of a standard workflow. The Optics package contains many other functions for more in-depth analysis, including generating ROC curves, confusion matrices, and analyzing the drivers of model error.
